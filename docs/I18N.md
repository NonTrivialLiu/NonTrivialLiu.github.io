# 中英文内容维护

本站以英文为默认语言，英文 URL 保持在根路径，简体中文放在 `/zh-cn/` 下。当前只启用了框架；官方 Demo 文本仍为英文，尚未创建任何简中译文。

```text
英文源文件（官方目录） ──┐
                        ├─ Jekyll Polyglot ── /al-folio/          英文
简中译文（zh-cn 子目录）─┘                    └─ /al-folio/zh-cn/ 简中

共享：_bibliography、assets、站点配置
分离：页面、文章、项目、动态、课程与界面字符串
```

## 内容放置规则

英文文件继续留在 al-folio 官方目录，避免为了多语言重排上游 Demo。开始翻译某一项时，只在对应集合下创建 `zh-cn` 子目录。

| 内容       | 英文源文件                     | 简中译文                             |
| ---------- | ------------------------------ | ------------------------------------ |
| 页面       | `_pages/about.md`              | `_pages/zh-cn/about.md`              |
| 博客       | `_posts/2025-01-01-example.md` | `_posts/zh-cn/2025-01-01-example.md` |
| 项目       | `_projects/example.md`         | `_projects/zh-cn/example.md`         |
| 动态       | `_news/example.md`             | `_news/zh-cn/example.md`             |
| 课程       | `_teachings/example.md`        | `_teachings/zh-cn/example.md`        |
| 书目       | `_books/example.md`            | `_books/zh-cn/example.md`            |
| 界面字符串 | `_data/en/i18n.yml`            | `_data/zh-cn/i18n.yml`               |

> `_bibliography/`、图片、PDF、音视频、JavaScript 和 CSS 保持单份共享。URL slug 继续使用英文。

## 翻译一个页面

1. 在英文源文件的 front matter 中加入稳定的配对标识：

   ```yaml
   lang: en
   page_id: about
   permalink: /
   ```

2. 复制该文件到对应的 `zh-cn` 子目录，并保持 `page_id` 与 `permalink` 完全相同：

   ```yaml
   lang: zh-cn
   page_id: about
   permalink: /
   ```

3. 只翻译新文件中的 `title`、`description` 和正文。布局名、资源路径、Liquid 标签、代码块及 `page_id` 保持原值。

4. 页面保存后，语言入口会自动从禁用状态变为可点击，并在当前中英文页面之间切换。Polyglot 同时生成 canonical 与真实译文对应的 `hreflang`；未翻译页面不会发布简中 `hreflang`。

### 博客与 Distill

博客文章使用相同日期和英文 slug，两个文件设置同一个 `page_id`。Distill 文章的公式、引用、脚本与图表写法保持不变，只翻译 front matter 中可读字段和正文。

```yaml
# English
lang: en
page_id: busbar-topology-gnn

# 简体中文
lang: zh-cn
page_id: busbar-topology-gnn
```

文章允许只提供一种语言。缺少译文时，语言入口保持禁用，原文仍按默认语言构建。

### 界面字符串

把自定义界面文字按相同键分别写入两个文件：

```yaml
# _data/en/i18n.yml
nav:
  research: Research
```

```yaml
# _data/zh-cn/i18n.yml
nav:
  research: 研究
```

模板中统一读取 `site.data.i18n.nav.research`。Polyglot 会在每种语言构建时自动合并相应的数据文件。

## 验证

完成一次翻译后运行：

```bash
docker compose exec -T jekyll bash test/integration_polyglot.sh
```

浏览器重点检查英文页、对应 `/zh-cn/` 页面、语言切换、Distill、搜索结果和资源加载。完整站点继续使用：

```bash
docker compose up -d
```
